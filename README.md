# Local Jungle Flex Masonry

To use this plugin simply install and activate it.  Then put this CSS _class_ selector on the parent node you want to transform the children to masonry.

```html
.masonry_gallery
```
For example the markup could look like:

```html
<div class="masonry_gallery">
    <div>one</div>
    <div>two</div>
    <div>three</div>
    <div>etc</div>
</div>
```

Or a list:

```html
<ul class="masonry_gallery">
    <li>One</li>
    <li>Two</li>
    <li>Three</li>
</ul>
```
